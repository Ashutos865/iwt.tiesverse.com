# Assets inbox

Drop files here instead of pasting them into chat, then just say the filename.

Chat attachments are rejected when an image is over 2000px on either side and
the request already carries several images — which a Retina screenshot always
is. Files read from disk have no such limit, and exact values (hex codes, font
metrics, image dimensions) can be extracted from them rather than estimated.

Anything in here is ignored by git, so it never lands in the public repo.
